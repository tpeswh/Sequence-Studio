🕒 版本演進歷程 (Version History) v2.9 Release
v2.9 正式版 (跨節點通訊備註修復) 2026-10-02
  • 通訊備註顯示修復：補齊跨節點一般通訊（包含傳入線備註與回傳線備註）的 SVG 繪製呼叫，輸入備註文字後即時於畫布兩側對齊呈現。
  • 流程圖轉換響應修復：修正流程圖 SVG 寬度屬性變數參照錯誤，恢復點擊轉換即時呼叫反應。
v2.8 正式版 (流程圖雙行結構化排版) 2026-10-01
  • 流程圖文字雙行分層：流程方塊與 Alt 分支全面升級為雙行結構，第一行標示端點通訊方向（A ➔ B 或 內部處理），第二行呈現動作與 API 呼叫名稱，架構層次更加分明。
  • 流程圖 Mermaid 語法同步優化：生成語法自動整合 <b>節點通訊</b><br/>動作內容 標記，在外部 Markdown 檢視同樣工整。
v2.7 正式版 (排版防碰撞與流程圖純淨版) 2026-10-01
  • 首筆通訊垂直邊距加大：首筆通訊起點擴增至 topPad + 75px，保留充足安全邊距，徹底消除文字標籤與節點框線重疊碰撞問題。
  • 流程圖預設排除回傳資訊：預設僅保留正向業務動線與決策分支，排除冗長的回傳步驟方塊，並提供勾選開關供自由切換。
v2.6 正式版 (時序轉流程圖跨維度版) 2026-10-01
  • 時序轉流程圖功能：新增「🔀 轉為流程圖」核心轉換器，自動將跨節點通訊、內部處理、區間說明與 Alt 分支編譯為邏輯流程圖。
  • Alt 分支編譯為決策菱形：自動映射為條件菱形並劃分「符合」與「不符」分支，最後安全匯流。
  • 多元匯出支援：流程圖支援向量 SVG 即時預覽、Mermaid flowchart TD 複製、以及匯出 PNG 圖檔與 SVG 向量圖。
v2.5 正式版 (全畫布同步純淨版) 2026-10-01
  • 移除 LocalStorage 快取：完全移除瀏覽器本地暫存，自動同步直接與本機或微軟 OneDrive 檔案實體對接，確保資料來源單一且安全。
  • 全畫布自動同步保障：自動儲存範圍涵蓋專案內全部畫布分頁，分頁切換、編輯、新增、複製與刪除皆納入自動同步。
  • 版面精簡化：移除頂部「版本歷程」按鈕，改由點擊版號標籤（v2.9）直接喚起彈窗。
v2.4 效能與架構強韌版 2026-10-01
  • AutoSave 離頁保護與失效清除：新增 beforeunload 防護，同步失敗時安全斷開 Handle 並主動告警。
  • 智慧選取邏輯全面統一：Alt 條件框架與 Note Over 區間說明全面支援節點相鄰推導。
  • 節點防誤刪保護：刪除節點時提供確認視窗以防相依連線清空；流程項目維持即時刪除。
  • 輸入去抖動 (Debounce)：導入 RAF 渲染節流，大型流程圖輸入打字維持 60fps 流暢無卡頓。
  • 標題與節點寬度自適應：自動測繪節點與全域標題字串寬度，動態延展排版，杜絕文字溢出。
v2.3 正式版 (操作互動進化 & 匯出強化) 2026-10-01
  • 智慧節點相鄰通訊流：選取節點後點擊「新增通訊」，預設由該節點出發發送至右方相鄰節點；若位於最右側節點則自動轉向發往左方節點。
  • 節點刪除保護機制：刪除節點時若包含關聯通訊連線，將彈出防誤刪提示，避免意外清除相依步驟。
  • PNG 匯出比例獨立：重構 PNG 匯出尺寸運算，產出圖檔尺寸完全鎖定畫布原始規格，徹底不受介面縮放比例影響。
  • 鍵盤 Delete 快捷刪除：選中節點或流程時，按下鍵盤 Delete 鍵即可迅速進行刪除。
v2.2 正式版 (雙向即時自動存檔 & 滾動體驗修復) 2026-10-01
  • 整合 File System Access API，支援連結本機與微軟 OneDrive 資料夾進行無感背景自動同步儲存。
  • 修復版本更新歷程彈窗滑鼠滾輪獨立滾動功能。
  • 頂端匯出選單簡化，專注產出 PNG、SVG 與 Mermaid 格式。
